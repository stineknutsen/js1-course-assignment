# Square Eyes - javascript 1 course assignment

![image](/images/Screenshot%202024-12-14%20at%2014.32.59.png)

A website for buying high quality movies.

## Description

The goal for this assignment was to build a user-friendly site to browse and purchase high quality films. The focus was on user experience, responsiveness, design and error handling.

- Home page containing a grid of all the products, as well as searching and sorting functionality.
- Easy to add films to the cart, remove them, and check out.
- Header and footer containing the essentials. Cart, privacy policy and terms & conditions.
- Responsive design that works well for mobile, tablet and desktop.

## Built With

- HTML: structure
- CSS: layout, styling, responsiveness
- JavaScript: films content
